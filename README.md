# Ghibli Adventure

Ghibli Adventure — это 2D браузерная игра с элементами RPG и инвентаря в стиле анимационной студии Гибли.

## Возможности
- Переход между 4 уникальными локациями с пиксель-арт фонами
- Управление мышью
- Персонаж и враги с полосками здоровья
- Система боя (автоматический бой с врагом, урон, защита, зелья)
- Рюкзак с 28 ячейками (Backpack Hero style)
- Сундуки с выбором предметов (меч, щит, зелье)
- Предметы влияют на бой (меч — урон, щит — защита, зелье — лечение)
- Стартовый экран с кнопкой "Начать игру"
- Фоновая музыка и музыка боя
- Модульная архитектура (логика рюкзака, боя, музыки, сброса игры вынесены в отдельные файлы)

## Как запустить
1. Запустите локальный сервер в папке проекта:
   ```
   python3 -m http.server 8000
   ```
2. Откройте в браузере [http://localhost:8000/](http://localhost:8000/)

## Структура проекта
- `index.html` — основной файл игры
- `backpack/` — логика и интерфейс рюкзака
- `music/` — музыка и музыкальный модуль
- `start/` — стартовый экран и сброс игры
- `items/` — логика и характеристики предметов
- `battle.js` — логика боя
- `game.js` — основной игровой модуль
